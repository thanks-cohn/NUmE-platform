# Future Living Blocks

This note defines vocabulary and interaction boundaries for a future premium webpage system. It does **not** authorize an implementation in the current gallery.

- **Living Block:** a premium merchant content block anchored at one vertical location in NUME.
- **Feature Pavilion:** the visible oversized placement between rows.
- **Living Perimeter:** moving gallery regions that remain visible around the focused block.
- **Theme Veil:** a translucent, merchant-colored surround that does not cover the entire viewport.
- **Anchored Folio:** premium horizontal page navigation contained inside one stationary block.
- **Contained Editorial:** vertical scrolling contained inside that same block.

## Non-negotiable spatial contract

> **Spatially anchored, internally navigable.**

Changing an Anchored Folio page must never move the visitor across marketplace blocks or alter the surrounding gallery position. Contained Editorial scroll belongs to its Living Block, while the marketplace and Living Perimeter retain their exact position.
